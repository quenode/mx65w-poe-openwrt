# MX65W probe artefacts

Reference copies only. **Nothing here is consumed by the build.**

The MX65W device profile is generated by `scripts/prepare-source.sh`, which
inserts it into `target/linux/bcm53xx/image/Makefile` on every run. That is
the supported path and it is idempotent.

`0001-add-meraki_mx65w-device-profile.diff` is a real unified diff against
upstream `7670f36`, kept for review and for anyone who wants to apply the
change by hand:

    git apply 0001-add-meraki_mx65w-device-profile.diff

It was previously a context diff (`479a480,493`) despite the name and the
`0001-` prefix, so `git apply` and `patch -p1` both rejected it.

The other files are snapshots of what a probe build produced:

| File | Contents |
|---|---|
| `config` | probe build configuration |
| `image-Makefile.mx65w-profile` | full image Makefile with the profile applied |
| `manifest` | package list from a probe build |
